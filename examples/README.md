# Configuration Examples

This directory contains example configuration files for Cline.

## MCP Configuration Example

`mcp.json.example` - Example MCP server configuration that can be placed in:
- Project root as `.mcp.json`
- VSCode settings directory as `.vscode/mcp.json`

For more information about MCP multi-source configuration, see [../docs/mcp-multi-source.md](../docs/mcp-multi-source.md).
